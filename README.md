# Foliver

基于 Vue、Tauri 和 Rust 的阅读应用，构建目标为 Windows、macOS、Linux、Android 和 iOS。

应用标识为 `com.xyz.foliver`，图标源文件为根目录的 `icon.svg`，使用 `npm run icons` 生成平台图标。

书源引擎基于 Legado 的 [Kotlin Multiplatform](https://github.com/huajideshutiao/legado) 实现。
